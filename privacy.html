Privacy

With the owner's authorization, this private tool uses read-only access to the account email, requested Gmail messages and Calendar events. OpenAI is approved to process relevant text for user-requested summaries and reply drafts. Training is disabled, per operator confirmation; this does not promise zero retention. This does not authorize automatic monitoring or other AI providers. Permitted use excludes sale, advertising and general-purpose model training. OAuth credentials are plaintext files with owner-only permissions in a private Docker volume. The selected policy for local conversation history is manual deletion; no automatic deletion schedule is promised. Provider retention, logs, exports and backups are separate. Revoking Google access stops future authorized reads but does not erase existing copies. These page files contain no tracking or cookie-setting code; GitHub Pages, if used, logs the visitor's IP address for security.
